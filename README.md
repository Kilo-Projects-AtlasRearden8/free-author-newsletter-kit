# Free Author Newsletter Kit

Fillable, printable newsletter templates and planning tools for authors —
no account, no signup, no email required. Just open, fill in, and print (or
copy into your email tool).

Created by **Asdale Dynamics, LLC** — beginner-friendly AI education, books,
and practical tools. Learn more at dylanasdale.github.io

## What's inside

| Template | Format | What it's for |
| --- | --- | --- |
| Welcome email | Markdown, HTML | First email new subscribers receive |
| Release announcement | Markdown, HTML | Announce a new book, guide, or tool launch |
| Signup ideas | Markdown, HTML | Reader-magnet and list-growth ideas |
| Sending calendar | Markdown, HTML | Quarterly newsletter sending plan |

## How to use

**Fillable HTML:** Open any `templates/*.html` file in your browser, click into
the fields, type your details, then print to paper or PDF via your browser's
print dialog. Print styles strip the screen-only chrome so the page comes out
clean on paper.

**Markdown:** Open any `templates/*.md` file in a text editor, replace the
`[bracketed placeholders]` with your own copy, and paste it into MailerLite,
ConvertKit, Substack, or whatever email tool you use.

No account is needed for anything in this kit. Nothing phones home. No secrets,
API keys, or personal data belong in these files — do not add any.
