Free Author Newsletter Kit

Fillable, printable templates for author newsletters — no account needed.

Created by Asdale Dynamics, LLC — beginner-friendly AI education, books, and practical tools. Learn more at dylanasdale.github.io. Behind the kit: Dylan Asdale, registered nurse turned AI author and founder of Asdale Dynamics, LLC (Indiana, formed Oct 2026).

Open any template below in your browser, click into the fields, type your details, then print to paper or PDF via your browser's print dialog. Or use the Markdown files and paste into MailerLite, ConvertKit, Substack, or whatever email tool you use.

What's inside

TemplateFormatWhat it's for
Welcome email Markdown HTML First email new subscribers receive — expectations, freebie delivery, reply invitation.
Release announcement Markdown HTML Announce a new book, guide, or tool launch — one offer, one call to action.
Signup ideas Markdown HTML Reader-magnet and list-growth ideas with checkboxes and a quarterly goal.
Sending calendar Markdown HTML Quarterly newsletter sending plan you can print and pin up.

How to use

  1. Fillable HTML: open templates/*.html in your browser, type into the bracketed fields, print to paper or PDF.
  2. Markdown: open templates/*.md in a text editor, replace the [bracketed placeholders], paste into your email tool.
  3. Print styles hide screen-only controls so the page comes out clean on paper.

No account is needed for anything in this kit. Nothing phones home. Do not add secrets, API keys, or personal data to these files.
